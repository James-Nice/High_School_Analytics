# 高中教学质量数据运营分析平台

## 1. 平台简介

高中教学质量数据运营分析平台是一款专为高中教学质量数据管理和分析设计的系统，支持对高一、高二、高三全年级、全班级、全学科的考试数据进行统一管理、自动统计、智能分析、动态监控、异常预警、报表输出与可视化展示。

## 3. 快速开始

### 3.1 环境准备

- **Node.js**：确保安装了 Node.js 14.0 或以上版本
- **npm**：Node.js 包管理器（随 Node.js 安装）

### 3.2 启动服务

#### 3.2.1 启动后端服务

```bash
# 进入后端目录
cd highschool-platform/backend

# 安装依赖
npm install

# 启动服务
node server.js
```

后端服务将运行在 `http://localhost:5000`

#### 3.2.2 启动前端服务

```bash
# 进入前端目录
cd highschool-platform/frontend

# 安装依赖
npm install

# 启动开发服务器
npm start
```

前端服务将运行在 `http://localhost:4000`

### 3.3 访问平台

在浏览器中打开 `http://localhost:4000`，即可访问高中教学质量数据运营分析平台。

### 3.4 默认账号

- **用户名**：admin
- **密码**：admin123

## 5. 核心功能详解

### 5.1 校排名分段统计

支持两种模式设置排名段：

1. **百分比模式**：按百分比设置排名范围（如 0%-10%、10%-20%）
2. **名次模式**：按具体名次设置排名范围（如 1-50名、51-100名）

设置特点：

- 自动保持段次连续性（上一段结束名次+1 = 下一段起始名次）
- 支持自定义段次名称
- 设置持久化保存到本地存储

### 5.2 总分分数段统计

支持自定义分数段设置：

- 按分数范围划分（如 600-750、500-599）
- 自动保持段次连续性（上一段起始分数-1 = 下一段结束分数）
- 统计各班各分数段人数

### 5.3 班级学科均值高低分对比

展示各班在选定学科的三项关键指标：

- **均值**：班级平均分数
- **最高分**：班级最高分数
- **最低分**：班级最低分数

图表特点：

- 柱状图展示三项指标对比
- 支持鼠标悬停查看详细数据
- 图例与柱形图对应显示

## 9. 常见问题

### 9.1 成绩导入失败

- **原因**：数据格式错误、字段缺失、分数超出范围
- **解决方法**：下载错误提示表，根据提示修改数据后重新导入

### 9.2 统计数据不准确

- **原因**：成绩数据不完整、考试设置错误
- **解决方法**：检查成绩数据是否完整，检查考试设置是否正确

### 9.3 预警信息不显示

- **原因**：预警阈值设置过高、数据不足
- **解决方法**：调整预警阈值，确保有足够的历史数据

### 9.4 系统运行缓慢

- **原因**：数据量过大、浏览器缓存问题
- **解决方法**：清理浏览器缓存，减少同时处理的数据量

### 9.5 排名段设置后数据不更新

- **原因**：未点击"保存并应用"按钮
- **解决方法**：设置完成后点击"保存并应用"按钮
